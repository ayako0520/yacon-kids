## AC06 素材一覧（ページで使った画像）

ページで使った画像は **0点** です。
`site/` の中に画像ファイルは無く、`<img>`・背景画像・OGP画像・ファビコン画像もありません（ファビコンは空指定）。

台帳に載っている素材と、このページでの扱いは次のとおりです。

## 試作で行った確認（2026-11-04）

- Chromium（Playwright）で、幅320・375・768・1280px の横スクロール・はみ出しなし
- H1が1つ、見出しの順序が飛ばないこと
- ボタン・選択肢・主要リンク・折りたたみの高さ44px以上
- 本文・選択肢・問題文の文字サイズ18px以上
- クイズ：未選択時の案内とフォーカス、矢印キーでの選択、回答後のフォーカス移動、つぎへ、結果、もういちど
- JavaScript 無効時に代替表示が出ること
- `prefers-reduced-motion: reduce` でスムーススクロールが止まること
- 外部へのリクエストが0件であること
- 1文40字を超える文が無いこと（ふりがな・【要監修】を除いて計測）
- 主な配色のコントラスト比（本文15.1:1、ボタン6.9:1、【要監修】7.9:1、選択肢の枠4.4:1 など）
